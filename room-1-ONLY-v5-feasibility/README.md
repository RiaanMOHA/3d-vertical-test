# ROOM-1 ONLY — feasibility research

## What this folder is

A sealed-off **research-only** investigation into rebuilding **room-1** with a 2026 cutting-edge stack (gaussian splats, WebGPU, AR, mobile). It contains feasibility prompts only — no code, no build, no installs.

## What this folder is NOT

- **NOT the master plan** for the Ozu-1 project. The Ozu-1 master plan covers the whole property — all rooms, exterior, full build sequence — and lives elsewhere.
- **NOT about any other room.** Scope is room-1 and room-1 only. Room-2, room-3, room-4, the exterior, and the unified building are explicitly out of scope.
- **NOT a build instruction.** These are research briefs that produce a report. Building, if it happens, is a later phase the user funds separately.
