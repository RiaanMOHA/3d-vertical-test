`addRoomTrim` originally created baseboards + crowns with single `trimMat` material. This session iterated:

2. Baseboard material array with top = floor color (Phase 11 - failed).

5. Crown material array with top = floor color (Phase 14 - failed). KEPT.

Final code state at `ozu-test.html:~1909-1914`:
```js
const matBaseFull = new THREE.MeshStandardMaterial({ color: 0xafa299, roughness: 0.9 });
const matCrownTop = new THREE.MeshStandardMaterial({ color: floorColor, roughness: 0.85 });
const crownMats = [trimMat, trimMat, matCrownTop, trimMat, trimMat, trimMat];
// In the for loop:
const mat = isCeil ? crownMats : matBaseFull;
```

BoxGeometry face order for the material array: `[+X, -X, +Y, -Y, +Z, -Z]`. Index 2 (+Y) is the top face.

If the next session determines the white lines are NOT crowns, the crown material array can be reverted to plain `trimMat` (the original behavior).
