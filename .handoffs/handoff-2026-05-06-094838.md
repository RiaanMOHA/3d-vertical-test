### Real-HDRI environment lighting (NEW this session)

Replaces the previous procedural 6-color cube `buildRoom1EnvMap` with HDRI-based IBL:

```js
let _room1EnvMap = null;
let _envLoaded = false;
const _pmrem = new THREE.PMREMGenerator(renderer);
_pmrem.compileEquirectangularShader();

function _buildFallbackEnvMap() {
  // procedural cube as before — used while HDRI loads asynchronously
}
function buildRoom1EnvMap() { return _room1EnvMap || _buildFallbackEnvMap(); }

new HDRLoader().load(
  'ozu-test/hdri/kloppenheim_06_puresky_2k.hdr',
  (texture) => {
    texture.mapping = THREE.EquirectangularReflectionMapping;
    const envMap = _pmrem.fromEquirectangular(texture).texture;
    _room1EnvMap = envMap;
    _envLoaded = true;
    texture.dispose();
    if (scene && scene.environment !== envMap) scene.environment = envMap;
  },
  undefined,
  (err) => { console.warn('HDRI load failed, using procedural fallback:', err); }
);
```

Result: PMREMGenerator builds a pre-filtered environment map from the HDRI suitable for `MeshStandardMaterial` and `MeshPhysicalMaterial` IBL. Both indoor and outdoor scenes get realistic indirect light reflecting a real photographed sky.

Trade-off: needs network on first load to download the HDRI; works offline thereafter (browser caches).

### Real refractive glass (NEW this session)

Both exterior `matGlass` and interior `glassMat` switched from:
```js
new THREE.MeshStandardMaterial({ color: 0x..., transparent: true, opacity: 0.55, roughness: 0.18 })
```
to:
```js
new THREE.MeshPhysicalMaterial({ color: 0xfafdff, roughness: 0.05, metalness: 0.0, transmission: 1.0, thickness: 0.01, ior: 1.52 })
```

In r184, `MeshPhysicalMaterial.transmission` simulates light passing THROUGH the surface, refracting based on `ior`. Real glass refracts at 1.50-1.52. The env map (now an HDRI sky) is what the viewer sees through the glass — proper specular reflection plus actual transmitted light.

Visual delta from old approach: glass picks up sky color, panes show realistic reflections at glancing angles, edges have subtle Fresnel falloff. Performance cost: significant — `transmission` triggers an extra render pass per material. With ~16 windows, watch framerate on mobile. Drop to 0.85 transmission or single-pane proxies if perf bad.
