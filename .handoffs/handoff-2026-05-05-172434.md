## Architecture and design notes

**Cloth shader pattern (established this session):**

For r128, native sheen support is absent. The `applyClothShader(material, sheenColor, sheenStrength)` helper at [ozu-test.html:5140-5158](ozu-test.html#L5140-L5158) uses `material.onBeforeCompile` to inject:
1. Two uniforms (`sheenColor`, `sheenStrength`) at the `#include <common>` injection point.
2. A fresnel-pow(1-NoV, 4.0) addition at the `#include <output_fragment>` point.

This adds a soft warm fringe at grazing angles that reads as fabric. Applied to: matCurt, matSheet, matPillowWhite, matPillowAccent. Skipped: matBand (small accent), matShade (has procedural linen texture already).

**Conservative tuning rule (reinforced this session):**

After the user rejected the painted_plaster_wall PBR set as "too rough", I deliberately tuned the cloth shader's `sheenStrength` LOW (0.15) instead of the plan's higher default. **The pattern: when the user rejects an aggressive visual change, dial down the next-similar change before asking. Easier to dial up than apologize for being too aggressive again.**

**Photo-faithfulness > tech-impressive (reinforced this session):**

The downloaded `painted_plaster_wall` PBR set was rejected not because of technical issues but because the asset's bumpy plaster style didn't match the room's smooth modern painted walls. The asset was deleted. **Future sessions should NOT redownload it.** The asset list in `room-1-ONLY-cutting-edge-plan.md` has a strikethrough + REMOVED entry to prevent this.

**The `pbrMatR1` helper convention (existed before this session):**

For new PBR-textured surfaces in room-1, use `pbrMatR1(slug, repU, repV, extras)`:
- `slug` matches the folder name in `ozu-test/room-1-textures/`
- `repU` / `repV` are texture repeats (typically `RW / 1.5` for ~1.5 m natural repeat scale)
- `extras` get spread into the final MeshStandardMaterial constructor (e.g., `{ color: 0x..., roughness: 0.7 }`)

The helper handles sRGBEncoding on diffuse, max anisotropy, RepeatWrapping. Future texture sets should follow this pattern.
